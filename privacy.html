Privacy Policy

Spark & Why Uploader is a private tool used only by the owner of the YouTube channel Spark & Why.

What the tool does

It uses the YouTube Data API to upload videos and thumbnails to the owner's own YouTube channel.

Data we collect

The tool does not collect, store, sell or share personal data about any other person. It only uses an access token that belongs to the channel owner, and that token is stored privately by the owner.

Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
